# Technical architecture review

Reviewed 2026-10-13. Scope: current repositories, READMEs/model cards, license declarations and documented requirements. No upstream model or GPU kernel was executed. Compatibility below is an assessment, not a successful integration test. Repository push dates and inspected commit SHAs are in [the snapshot](source-snapshot.json); a recent push is evidence of activity, not a support guarantee.

## Decisions

The first stack should establish whether shared perception supervision improves both directions. It does not need a custom language architecture. A 2–5B-total, 300–800M-active model is a later hypothesis, not the starting budget. Knowledge lookup, chemistry identifiers and usage restrictions remain outside language-model weights.

## Smallest coherent stack

1. E0: Python, NumPy, JSONL, a frozen registry/ontology and two regularized linear encoders into observed attribute space. CPU only.
2. E1: PyTorch + Transformers + PEFT, using [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) as a reproducible small language benchmark. Its model card declares Apache-2.0, 0.6B parameters and Transformers support. Pin an actual revision before running; use non-thinking mode and bounded output length.
3. SFT via TRL when needed, XGrammar for formula JSON, deterministic validation for meaning. Plain PyTorch for mixture/latent learning.
4. Add optional molecular feature extraction in a separate environment. No PithTrain, Soup, Unsloth, TIDE, EAGLE, vLLM or custom kernel dependency is required for E0.

This selection is a project design decision derived from the review. None of the upstream throughput claims has been reproduced here. No source dataset or pretrained checkpoint has been downloaded into this repository.
